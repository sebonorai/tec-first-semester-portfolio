# Pensamiento Computacional – C++

Materia cursada durante el primer semestre de Ingeniería en Tecnologías Computacionales
en el Tecnológico de Monterrey (Campus Monterrey).

Este directorio contiene tareas y proyectos desarrollados en **C++**,
enfocados en el desarrollo del pensamiento computacional,
la lógica de programación y la programación orientada a objetos.
