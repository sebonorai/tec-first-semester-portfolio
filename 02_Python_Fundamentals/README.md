# Python – Fundamentos de Programación

Durante el primer semestre se trabajaron los fundamentos de programación
utilizando **Python**, reforzando la lógica, la estructura del código
y la resolución de problemas.

## Temas cubiertos
- Variables y tipos de datos
- Condicionales (`if / else`)
- Ciclos (`for`, `while`)
- Funciones
- Listas y estructuras básicas

## Objetivo
Construir una base sólida en programación con Python,
facilitando el aprendizaje de otros lenguajes y cursos posteriores.
